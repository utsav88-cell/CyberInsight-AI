## 🛡️ CyberInsight AI ##

# Intelligent Cyber Threat Analysis Platform

### 📌 Project Overview

CyberInsight AI is an AI-assisted cybersecurity platform that performs static security analysis of APK files, EXE files, and URLs before they are installed or executed.

The project helps users understand potential cyber threats through AI-generated explanations, risk scores, and security recommendations.



## 🎯 Problem Statement

Many users unknowingly install malicious applications or open unsafe files because existing cybersecurity tools often generate technical reports that are difficult for non-technical users to understand.

CyberInsight AI aims to simplify cybersecurity by providing AI-assisted threat explanations in easy-to-understand language.



## 🚀 Features

- APK Static Analysis
- EXE Static Analysis
- URL Analysis
- SHA-256 Hash Generation
- Permission Analysis
- Certificate Verification
- AI-Assisted Threat Explanation
- Risk Score Generation
- Security Recommendations
